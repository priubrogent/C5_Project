# Week 1 — Object Detection on KITTI-MOTS

Off-the-shelf inference, quantitative evaluation, and LoRA fine-tuning of Faster R-CNN, DeTR, RT-DETR, and YOLO on the KITTI-MOTS dataset (person + car).

## Requirements

```bash
pip install torch torchvision
pip install transformers peft
pip install albumentations
pip install pycocotools
pip install ultralytics      # YOLO only
pip install wandb tqdm Pillow numpy opencv-python
```

## Dataset setup

Each script has a `DATASET_PATH` constant near the top. Set it to the `training/image_02` folder of your KITTI-MOTS download:

```python
DATASET_PATH = "/path/to/KITTI-MOTS/training/image_02"
```

The COCO-format ground-truth file `kitti_mots_to_coco_gt.json` must exist at `Week1/`. It is generated by `utils/GT_conversor.py` if missing.

## Wandb (optional)

Scripts log to wandb by default (entity `veridas`). To disable it:

```bash
export WANDB_MODE=disabled
```

Or set `report_to="none"` in `TrainingArguments` before running.

## RT-DETR

Run from `Week1/`.

**1. Evaluate the pretrained model (baseline)**

```bash
python RT-DETER/evaluate_pretrained.py
```

Runs `PekingU/rtdetr_r101vd` on the validation split and saves COCO metrics + visualizations to `RT-DETER/Results_RTDETR/pretrained_eval/`.

**2. Fine-tune with LoRA + COCO weight initialization**

```bash
python RT-DETER/finetune_fixed3.py
```

Applies LoRA to the attention layers and initializes the 2-class detection heads from the pretrained COCO person/car weights. Saves the LoRA adapter and detection head weights to `RT-DETER/Results_RTDETR/finetune_fixed3/final_lora_adapter/`.

**3. Evaluate and visualize the fine-tuned model**

```bash
python RT-DETER/visualize_finetuned.py
```

Loads the adapter from step 2, runs COCO evaluation on the full validation split, and saves per-sequence visualizations to `RT-DETER/Results_RTDETR/finetune_fixed3/visualizations/`.

## YOLO

Run from `C5_Project/` (the parent of `Week1/`).

```bash
python -m Week1.YOLO.main_run --task <task>
```

| `--task` | Description |
|----------|-------------|
| `c` | Off-the-shelf YOLOv10 inference |
| `d` | Evaluation — COCO mAP on validation split |
| `e_defreeze` | Fine-tuning by gradually unfreezing the last layers |
| `e_lora` | LoRA fine-tuning |
| `v` | Visualize predictions on the first frame of each sequence |

The model checkpoint (`yolo26m.pt`) and dataset path are set at the top of `YOLO/main_run.py`.
